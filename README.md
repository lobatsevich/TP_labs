## Описание проекта

Учебный Maven-проект на Java 17, посвящённый созданию и использованию
функциональных интерфейсов, лямбда-выражений и ссылок на методы.

Для каждой задачи реализованы два варианта решения:

- с использованием собственного функционального интерфейса;
- с использованием стандартного функционального интерфейса из пакета
  `java.util.function`.

Результаты работы демонстрируются в классе `Main`, а корректность решений
проверяется модульными тестами JUnit Jupiter.

## Выполненные задания

### Задание №6 — вычисление дискриминанта

Для квадратного уравнения `ax² + bx + c = 0` вычисляется дискриминант по
формуле:

```text
D = b² - 4ac
```

Реализованы следующие варианты:

- собственный интерфейс `TripleFunction`, принимающий три аргумента типа
  `double`;
- стандартный интерфейс `ToDoubleFunction<double[]>`, принимающий массив из
  трёх коэффициентов.

Для стандартного варианта выполняется проверка входного массива: он не
должен быть `null` и должен содержать ровно три коэффициента.

### Задание №18 — подсчёт вхождений цифры

Реализован подсчёт количества вхождений заданной цифры в целое число.
Поддерживаются положительные и отрицательные числа, ноль и
`Integer.MIN_VALUE`.

Использованы:

- собственный интерфейс `CustomCounter`;
- стандартный интерфейс `ToIntBiFunction<Integer, Integer>`.

В качестве аргументов передаются число и искомая цифра. Допустимы только
цифры от `0` до `9`; при передаче другого значения выбрасывается
`IllegalArgumentException`.

### Задание №30 — проверка принадлежности точки многоугольнику

Реализована проверка, находится ли точка внутри заданного многоугольника.
Для этого используется алгоритм пересечения горизонтального луча с рёбрами
многоугольника.

Использованы:

- собственный интерфейс `CustomPolygonPredicate`;
- стандартный интерфейс `BiPredicate<Point, List<Point>>`.

Точка, лежащая на границе многоугольника, считается находящейся внутри.
Многоугольник должен содержать не менее трёх точек, а его точки не могут быть
`null`.

### Основные классы

- `Main` — демонстрация работы всех реализованных заданий.
- `TripleFunction` — собственный функциональный интерфейс для трёх аргументов.
- `CustomCounter` — собственный интерфейс для подсчёта цифр.
- `CustomPolygonPredicate` — собственный предикат для проверки точки.
- `Point` — неизменяемая модель точки на плоскости.
- `DiscriminantService` — вычисление дискриминанта двумя способами.
- `DigitCounterService` — подсчёт вхождений цифры двумя способами.
- `PolygonService` — проверка принадлежности точки многоугольнику двумя
  способами.

## Проверки и тестирование

Тесты проверяют:

- применение собственного интерфейса `TripleFunction`;
- вычисление дискриминанта;
- обработку некорректного количества коэффициентов;
- подсчёт цифр в положительных и отрицательных числах;
- обработку нуля и `Integer.MIN_VALUE`;
- отклонение недопустимых значений цифры;
- определение точки внутри и снаружи многоугольника;
- обработку точки на границе;
- отклонение многоугольника, содержащего менее трёх точек.

## Запуск проекта

### Запуск тестов

Выполните из корня проекта:

```shell
mvn clean test
```

Команда удаляет предыдущие результаты сборки, компилирует исходный код и
запускает все модульные тесты.

### Запуск демонстрации

Соберите проект:

```shell
mvn clean package
```

Затем запустите класс `org.example.Main` из IDE. В IntelliJ IDEA это можно
сделать, открыв файл `src/main/java/org/example/Main.java` и нажав кнопку
запуска рядом с методом `main`.

В консоль будут выведены результаты вычисления дискриминанта, подсчёта цифр и
проверки точки на принадлежность многоугольнику.

## Логирование

Для вывода результатов используется Log4j 2. Конфигурация находится в файле
`src/main/resources/log4j2.xml`. Сообщения выводятся в консоль и содержат
время, уровень логирования, имя класса и текст сообщения.

Пользовательский графический интерфейс в работе не реализован: взаимодействие
с программой выполняется через демонстрационный класс `Main`, а проверка
основной логики — через автоматизированные тесты.
