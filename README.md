## Лабораторная работа №6

### Выполненное задание (Вариант №6: Вагон)

- **Разработана система управления железнодорожными вагонами:** Создана модель вагона с регистрационным номером, пунктом назначения, владельцем, снаряжённой массой и текущим статусом.
- **Реализовано управление состояниями вагона:** Добавлены статусы «загрузка», «разгрузка», «в пути», «в ремонте», «готов к отправке» и «требуется ремонт». Переходы между состояниями выполняются с учётом допустимых операций.
- **Реализована отправка вагона в пункт назначения:** Добавлен метод отправки, который проверяет возможность отправления и изменяет статус вагона на «в пути».
- **Добавлены операции обслуживания и ремонта:** Реализованы методы технического обслуживания, отметки о необходимости ремонта и выполнения ремонта с проверкой текущего состояния вагона.
- **Создан класс `FreightWagon` для грузовых вагонов:** Добавлена возможность загружать и разгружать груз, проверять допустимую массу груза и вычислять общую массу вагона с грузом.
- **Создан класс `Cargo` для описания груза:** Реализовано хранение названия, массы, ценности и признака хрупкости груза.
- **Создан класс `PassengerWagon` для пассажирских вагонов:** Добавлены возможности посадки и высадки пассажиров, проверки вместимости вагона и определения количества свободных мест.
- **Реализована фабрика `WagonFactory`:** Создание грузовых и пассажирских вагонов вынесено в отдельный класс. Предусмотрено создание вагона по указанному типу.
- **Создан сервис `RailwayService`:** Реализовано добавление вагонов в систему, поиск по регистрационному номеру, получение списка вагонов и выполнение основных операций управления.

### Выполненные требования к архитектуре и коду

- **Применены интерфейсы:** Созданы интерфейсы `Manageable`, `Transportable`, `Repairable`, `Serviceable` и `Loadable`, определяющие возможности управления вагоном, отправки, ремонта, обслуживания и работы с грузом.
- **Использовано наследование:** Абстрактный класс `Wagon` содержит общие свойства и поведение вагонов. Классы `FreightWagon` и `PassengerWagon` расширяют его функциональность с учётом особенностей каждого типа.
- **Применено перечисление `WagonStatus`:** Для хранения текущего состояния вагона используется `enum`, что позволяет ограничить набор допустимых статусов.
- **Реализована проверка входных данных:** Добавлена валидация регистрационных номеров, владельцев, пунктов назначения, массы вагона, характеристик груза и вместимости пассажирских вагонов.
- **Предусмотрена обработка ошибочных операций:** Проверяется возможность загрузки и разгрузки, отправки вагона, обслуживания и ремонта. Для недопустимых действий предусмотрены исключения.
- **Предотвращено добавление дубликатов:** `RailwayService` проверяет уникальность регистрационных номеров вагонов при добавлении в систему.
- **Соблюдена пакетная структура Maven-проекта:** Классы распределены по пакетам `entity`, `interfaces`, `factory` и `service`. Конфигурация логирования размещена в `src/main/resources`, а тесты — в `src/test/java` с соответствующей структурой пакетов.
- **Интегрирована система логирования Log4j 2:** Подключены библиотеки `log4j-api` и `log4j-core`. Настроен вывод сообщений в консоль с указанием времени, уровня важности и имени класса.
- **Добавлено логирование основных операций:** Регистрируются создание и добавление вагонов, отправка, загрузка и разгрузка, посадка и высадка пассажиров, обслуживание и ремонт.
- **Подготовлены модульные тесты JUnit Jupiter:** Созданы тесты для базового класса вагона, грузовых и пассажирских вагонов, фабрики и сервиса управления. Проверяются основные операции, ограничения, корректность изменения состояний и обработка исключений.
- **Пользовательский интерфейс не реализован:** Работа приложения проверяется посредством автоматизированных модульных тестов.
- **Настроен запуск тестов через Maven:** Для компиляции проекта и выполнения тестов используется команда `mvn clean test`. Для запуска тестов настроен `maven-surefire-plugin`.
